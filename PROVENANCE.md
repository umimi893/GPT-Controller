# Provenance

GPT Controller is the public distribution of the execution architecture proven in the private Q-Agent V4 project.

The public repository is intentionally created from a clean current-source snapshot with a new Git history. Private control branches, Action/Result history, machine configuration, deployment profiles, local paths and credentials are not copied into the public repository.

The internal Python package and `q-agent-v4` wire protocol are retained for compatibility and migration safety. User-facing installation paths, Scheduled Tasks, documentation and the default private control branch use GPT Controller names.
